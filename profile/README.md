# ⚠️ Approov Beta — Candidate and Pre-Release

> **NOTICE:** Repositories hosted under this organization are **beta and pre-release candidate builds**. 
> - **Feature Complete, Pending Final Hardening:** APIs and architectures are largely settled, but software here may still have edge-case bugs, performance quirks, or minor interface adjustments.
> - **Pre-Production Use Only:** Intended for staging, integration testing, and customer validation. Do not deploy these packages or source code directly into production environments.
> - **Official Releases:** For stable, general-availability (GA) releases with enterprise SLAs, visit **[github.com/approov](https://github.com/approov)**.

---

### Release Candidate Testing and Feedback
We encourage customers and partners to validate these builds against your real-world staging pipelines and provide feedback before GA:

* **Consumption:** All software here is provided as public source code for review, testing, and staging integration.
* **Reporting Issues:** Found a regression, unexpected behavior, or integration issue? Please open an **Issue** directly in the respective repository.
* **Contributing Fixes:** Pull requests from forks are welcome. Please refer to our [Contributing Guidelines](CONTRIBUTING.md) for testing and PR conventions.
* **Promotion to Production:** Once repositories meet release criteria and sign-off, they are transferred directly to **[github.com/approov](https://github.com/approov)** without breaking existing Git remotes or issue histories.
